# Підтвердження людських міток

2026-10-29 отримано явне підтвердження всіх30 запропонованих міток після перегляду та дозвіл на freeze-коміт і пілот. Фінальні рішення збережено в evals/sets/l09_labels.jsonl; [доказ порядку](../evidence/chronology.json), [freeze](../evidence/labels-freeze.json).

У ground_truth_from/why_disputed збережено початкові пояснення з чернетки, включно з історичним префіксом «Потребує підтвердження». Після підтвердження він не означає відкритий review: поточні label_status=human_review_confirmed, human_review_confirmed=true та labeled_on фіксують завершення. Після першого виходу судді ці тексти й мітки не переписуються.

Це підтвердження запропонованих міток, а не незалежний другий розмітник. За цим набором не заявляється міжекспертна узгодженість. Чернетка лишається окремо для походження.
