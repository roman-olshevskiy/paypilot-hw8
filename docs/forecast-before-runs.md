# Прогноз до першого платного запуску ДЗ8

Чернетковий прогноз: на 12-кейсовому зрізі очікується збіг10/12; на30 —24/30. Це очікування, не результат. Перед оплатою прогноз і підтверджені людські мітки мають бути закомічені.

Очікувані складні класи: непряма згадка людини, м’які обіцянки (should/confident), нечітке розкриття внутрішньої причини, українські еквіваленти. Самоузгодженість може бути високою і при помилковому вердикті. Зсув довжини може не проявитися на D18; не підбирати відповіді після перегляду судді.

Налаштування-кандидат: агент OpenRouter Haiku5.5; суддя прямий Anthropic claude-haiku-5-5, TEMP0.7. Model ID є в GET-каталозі; підтримка inference/temperature ще НЕ перевірена. Та сама модель створює невиміряний ризик self-preference; порівняння другого судді не оголошується виконаним.

## Уточнення конфігурації ДО першого inference · 2026-10-29

Первинний кандидат Haiku5.5 не підтримує temperature0.7 (офіційний migration guide); жодного inference з непідтримуваним параметром не виконувалося. Обрано judge_model=claude-haiku-4-5-20251001, TEMP0.7, без thinking, прямий Anthropic. Цей ID є в GET-каталозі. Агент лишається OpenRouter Haiku5.5, тому моделі розведені, але це не окреме вимірювання самопереваги.

Прайс судді: USD1/M input, USD5/M output, cache-read0.10, cache-write5m1.25. До300 judge calls попередньо резервуємо USD2.50 до оцінки за пілотом; це верхній плановий резерв, не дозвіл автоматично запускати повну серію. Пілот:3 judge calls (HW8-01,11,25, по1) та4 agent chats (ESC-001/002 ×clean/lesson-09, по1). Пілот не входить у фінальні5.

Джерела: https://platform.claude.com/docs/en/models/haiku-5-5/migration-guide ; https://platform.claude.com/docs/en/models/haiku-4-5/overview . Прогнози10/12 і24/30 не змінені після виходу моделі, бо жодних виходів ще немає.
