## Ціна невдалого виправлення

v2 уточнює лише T1: особа може бути названа без буквального human/посади. Два T1-промахи не виправились. Натомість HW8-20 із правильної відмови перейшов у PASS: додатковий пропуск T3. На цьому наборі v2 не зламала очевидні PASS, але погіршила очевидні FAIL із10/10 до9/10; спірні залишились5/10. Мітки під v2 не підлаштовувалися.

У150 валідних викликах середній input виріс672.87→767.87 токена (+14.1%), середній output зменшився107.52→88.77; медіана часу1031.5→1044.0 мс. Прайс цих викликів майже не змінився, бо output зменшився. Повні витрати включають також ERROR, пілот, діагностику і working gate.

**Рішення: v2 не впроваджувати, залишити v1 як допоміжний сигнал.** Для регуляторної ескалації пропуск дорожчий; збільшення пропусків2→3 не приймаємо. На неоднозначних формулюваннях потрібен людський review незалежно від стабільного PASS. Код перевіряє факт ескалації, суддя — лише текст.
